## 🚀 Deployment

This static site requires zero build steps and can be deployed in under 60 seconds to:
- **Vercel** (`vercel deploy`)
- **GitHub Pages** (`Settings` → `Pages` → `Branch: main`)
- **Netlify** (Drag and drop folder)
